# Story Desk

An offline, voice-first interview app for developing a novel. It asks staged questions, suggests follow-ups based on what you said, checks answers against your own rules for the book, and keeps a story bible and a scene board. It writes none of the book.

This is a personal build, hosted here so it can be installed on an iPad as a home-screen web app and used without a connection.

## Use

Open https://miguelseb.github.io/story-desk/ in Safari on the iPad, tap Share, then Add to Home Screen. Open it once from the Home Screen while online. After that it runs offline. All answers are stored only on the device, so use Backup > Save backup file regularly.

## Files

`index.html` is the whole app: styles, fonts, question pack and code in one file. `sw.js` keeps the offline copy. `manifest.webmanifest` and the two icons are for the Home Screen install. The `guide-*.png` files are screenshots used in the walkthrough document.
